Day 7 of 100: Morse Keys, an iPhone keyboard where you type in dots and dashes.

Install it once, then in any app (Messages, Notes, Safari) hold the globe key and switch to Morse.

→ Two big keys: dot and dash
→ Pause and the letter types itself (or end each letter by hand)
→ A strip shows your code, what it spells right now, and every letter it could still become
→ Backspace takes back the last dot or dash before it deletes a character

It also has a practice pad and a code chart, so you can learn before you switch.

The part I care about: it never asks for Full Access. iOS keeps the keyboard off the network, so nothing you type goes anywhere.

The Morse table came from a Morse trainer app I built earlier for learning CW, so today was all about the keyboard itself.

Would you actually text someone in Morse? "HI" is just six dots.
