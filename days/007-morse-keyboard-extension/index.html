Morse Keys

An iPhone keyboard where you type in dots and dashes, in any app: Messages, Notes, Safari.

What it does

  • Two big keys, dot and dash. Keys fire on touch-down, so fast keying doesn't drop symbols.
  • Pause and the letter types itself. 0.6, 0.9 or 1.3 seconds, or switch to Manual and end each letter yourself.
  • A live strip shows the code so far, what it spells right now, and every letter it could still become. Tap one to finish early. It turns red when the code can't be anything.
  • Backspace takes back the last dot or dash first, then whole characters.
  • Shift, auto-capitals at the start of a sentence, and a return key that says send, go or search when the app asks for it.
  • Practice pad and code chart in the app, so you can learn before you switch keyboards.
  • No Full Access, ever. iOS keeps the keyboard off the network. Nothing you type is stored or sent.

Try it

  1. Clone August85/ship100 and open days/007-morse-keyboard-extension/app.
  2. Run xcodegen (install with brew install xcodegen), then open MorseKeys.xcodeproj and press Run. Needs iOS 17 or later.
  3. On the phone: Settings › General › Keyboard › Keyboards › Add New Keyboard… › Morse Keys. Then hold the globe key in any text field and pick Morse.
