# Kid-safe YouTube Playlist Builder

Day 13 of [Ship 100](https://august85.github.io/ship100/). Web app.
Live: https://august85.github.io/ship100/days/013-kid-safe-youtube-playlist-builder/

**Plan**
1. Main flow: pick topics (big emoji tiles) and a screen-time limit (10/15/20/30 min) → get a playlist → play it full-screen in the page → "All done!" screen when it ends.
2. Engine: the duration-fitting picker from WalkPlaylists, with the walk length swapped for a screen-time ceiling and the budget shared across topics.
3. Data: a bundled, vetted catalog (`catalog.js`) built from an allowlist of kids' channels. No API key, no server, no search box.
4. Kid-safe means: only allowlisted videos ever play (shared links too), no autoplay into YouTube's suggestions, privacy-enhanced (`youtube-nocookie.com`) player, and a press-and-hold exit for grown-ups.
5. Out of scope: live YouTube search, signing in, publishing playlists to a YouTube account, per-child profiles.

## What it does

- **Pick** topics: Animals, Ocean, Space, Dinosaurs, How things work, Numbers, Letters, Songs, Move & yoga, Stories (topics with no videos are hidden).
- **Pick** a length. The playlist never runs more than about a minute past it.
- **Channels**: untick any channel you'd rather skip; the choice is remembered on this device.
- **Play** runs the list in a full-screen player. Each video ends → the next one starts → after the last one the screen says "All done!" instead of showing more videos. A countdown shows how much time is left. A small hand can press "Next", but leaving the player needs a 1.5-second press and hold (mouse, touch, or holding Enter/Space).
- **Shuffle again**, remove single videos, **Save** (up to 12 on this device), **Copy link** (the link carries only video ids; anything not in the catalog is dropped when it opens).
- **Open on YouTube** makes a temporary `watch_videos` playlist on youtube.com, for a TV or the YouTube app. It is labelled as not kid-safe, because suggestions there are YouTube's.

## Reused

From `YoutubeAutoPlaylist` (WalkPlaylists, read-only): `PlaylistGenerator.selectByDuration`, the greedy pick from the start, middle or end of the duration-sorted list, is ported to `engine.js`. Changes: the tolerance is one minute instead of ten (a screen-time limit is a ceiling, a walk isn't), each topic gets an equal slice of the budget, and the list is reordered so the same channel rarely plays twice in a row. The channel-uploads idea is from its cheap "recent likes" mode.

## Data

`catalog.js` is generated by `tools/build-catalog.mjs`, keyless:
- video ids and titles from YouTube's public RSS feeds for each channel's popular and long-form uploads (`UULP…` / `UULF…` playlists),
- embeddability from YouTube oEmbed (a video that refuses embedding is left out),
- length from the public watch page; only 1–25 minute videos are kept, Shorts/live/trailers are skipped,
- topics from title keywords, falling back to the channel's main topic.

The allowlist is 13 channels (SciShow Kids, Sesame Street, PBS KIDS, Nat Geo Kids, Super Simple Songs, Cosmic Kids Yoga, Art for Kids Hub, Numberblocks, Jack Hartmann, Peekaboo Kidz, Free School, Octonauts, StoryBots).

**Today's catalog has 103 videos from the first 6 channels.** Partway through the build YouTube's watch pages started answering "unusual traffic", so the script stopped instead of retrying. It now stops by itself when that happens, waits 0.4 s between videos, and merges with the previous catalog, so running it again later fills in the rest without losing anything:

```bash
cd days/013-kid-safe-youtube-playlist-builder
node tools/build-catalog.mjs            # fetch + merge
node tools/build-catalog.mjs --offline  # just rewrite catalog.js (e.g. after editing topic words)
```

## Decisions made during the unattended build

- No API key mode. A keyed live search would bring back exactly the risk this app is meant to remove; a vetted bundled list is the safer default.
- The player uses YouTube's own IFrame API script (`youtube.com/iframe_api`), which is the only way to know when a video ends. It isn't on the cdnjs/jsdelivr/unpkg list in RUNNER.md, but there is no substitute for it.
- YouTube's pause screen can still show "More videos" from the same channel (`rel=0` limits suggestions to the channel; it can't remove them). Since every channel is on the allowlist, that's acceptable, but worth knowing.
- Thumbnails load from `i.ytimg.com`.
- "Not affiliated with YouTube or any channel listed" is in the footer; channel names are only used to label their own videos.
